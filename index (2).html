      GitHub → Vercel 3단계 배포

      Zero Config
      1. 01. 압축 해제: 내려받은 date-mate-github.zip의 압축을 풀어 index.html 파일을 확인합니다.
      2. 02. GitHub 업로드: 새 저장소(Repository)에 index.html과 README.md를 드래그 업로드하거나 Git으로 푸시합니다.
      3. 03. Vercel 즉시 배포: Vercel에서 해당 GitHub 저장소를 Import 후 별도 빌드 명령 없이 바로 Deploy를 누르면 완료됩니다.
